# Oraculo Privacy Policy

Last updated: 2026-07-28

Oraculo is a daily phrase and color app. It does not require an account, show ads, use third-party analytics, or track users across apps or websites.

## Data Stored On Device

Oraculo stores the current phrase and color, Widget state, corpus version, a random installation identifier, recent phrase exposure history, and optional location context in the App's local shared container. The random installation identifier is used only to vary phrase and color selection on that device.

## Optional Location Context

Location context is off by default. Oraculo requests When In Use location access only after the user taps the location control, reads the in-app explanation, and chooses to continue.

When enabled, Oraculo converts coordinates to a coarser representation before caching them and sends rounded latitude and longitude to Open-Meteo for current weather or elevation lookup. Approximate location is used only for App Functionality, is not linked to an account, and is not used for advertising or tracking.

Users can disable location context at any time. Disabling it stops location, weather, and elevation requests and clears locally cached coordinates, location-derived weather, region, altitude, and geo-cell values. Users can also revoke location permission in iOS Settings.

## Network Requests

Oraculo may request static corpus updates from `https://oraculo-corpus.vercel.app/oraculo/`. If location context is enabled, it may request weather and elevation data from `https://api.open-meteo.com/`. If network requests fail, the App continues to work with bundled offline data.

Third-party services process requests under their own service terms and privacy practices.

## User Choices

Users may decline location permission, disable location context and clear related local caches, manage permission in iOS Settings, or uninstall the App to remove App data managed by iOS.

## Changes

If Oraculo's data handling changes materially, this policy will be updated and the new date will be shown above.
