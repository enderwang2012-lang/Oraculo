# 2026-08 语料全量初始审核

## 审核口径

本轮把 `starbucks_now_passphrases.csv` 的 248 条记录全部视为从未向用户曝光的初始候选。审核不读取或继承旧的 `new`、`anchor`、`cooling`、`retired` 结论，也不以疲劳、轮换批次或历史权重决定取舍。

每条记录只按中文质量、英文自然度、Oraculo 语气、语义重复、情境正确性和来源语境依赖重新判断。原始中文、主题、证据和来源 ID 继续保留，不用建议稿覆盖来源台账。

## 改写建议

原 13 条 `needs_rewrite` 在 `review/corpus_review_2026_08_full.csv` 和 `config/phrase_editorial_review.json` 中保留原文、最终改写方向、`proposedPhrase` 与 `proposedEnglish`，并已直接晋级为 `keep + active + approved`。例如：

- `他夏了夏天` → `夏了夏天`
- `悄悄惊艳大家` → `悄悄惊艳`
- `自由在风里` → `答案在风中`
- `总有远方可奔赴` → `奔赴`

改写稿不覆盖原始来源记录。构建时 `proposedPhrase` 与 `proposedEnglish` 作为最终展示的 `text` 与 `textEn`，不会回退到原始文案。
